# src/data/icmr/

Generated by `scripts/extract_icmr.py` (§5) — not checked in yet, since producing it
needs network access to nin.res.in, which this repo's sandbox environment blocks (see
that script's module docstring for the full explanation and what's actually been
verified vs. not).

Run `python scripts/extract_icmr.py` from the repo root (after
`pip install -r scripts/requirements.txt`) to populate this directory with:

- **icmr_ifct2017.json** — an array of `ICMRFoodItem` (§4.2), one per food in the IFCT
  2017 book's Table 1.
- **icmr.meta.json** — extraction metadata (§5.5): source PDF checksum, extraction
  date, row count vs. the expected 528, and any group-count mismatches to investigate.

This is a one-time extraction, not something that runs on a schedule (§5.2 — it's a
static, versioned publication) — re-run it only if NIN revises the source PDF (the
checksum in icmr.meta.json is what tells you if it has).
